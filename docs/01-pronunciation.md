# 🔊 西班牙语发音完全教程：一周就能「见词能读」

> 西班牙语是「所见即所读」的语言：**规则少、例外几乎为零**，认真学一周就能读出任何单词。
> 例词听真人读：[Forvo 西语](https://zh.forvo.com/languages/es/)、
> [SpanishDict](https://www.spanishdict.com/)（查词自带清晰发音）、**有道词典 App**（查词点喇叭）。

## 一、五个元音：西语发音的地基（比英语简单 10 倍）

西语只有 5 个元音，**发音永远不变**，没有英语那种一个 a 八种读法的破事：

| 字母 | 发音 | 例词 |
| --- | --- | --- |
| a | 啊 | casa（房子）ka-sa |
| e | 诶 | mesa（桌子）me-sa |
| i | 衣 | sí（是）si |
| o | 欧 | como（如何）ko-mo |
| u | 乌 | tú（你）tu |

> 先练到「看到元音条件反射读对」，后面全是搭积木。

## 二、辅音：只讲和拼音/英语不一样的

| 字母 | 规则 | 例词 |
| --- | --- | --- |
| **h** | 永远不发音 | **h**ola（你好）读「欧拉」 |
| **j** | /x/，像拼音 h 加重（喉咙摩擦） | **j**amón（火腿）「哈蒙」 |
| **ñ** | /ɲ/，「尼呀」连读 | Espa**ñ**a（西班牙）「诶斯巴尼亚」 |
| **ll / y** | 多数地区读「衣呀」 | pae**ll**a「巴诶亚」、**y**o（我）「哟」 |
| **v** | 和 b 完全同音！ | **v**ino 读「比诺」——西语没有英语的 v 音 |
| **z** | 西班牙读 /θ/（咬舌 s），拉美读 /s/ | **z**apato（鞋）。两种都对，选一种即可 |
| **c** | c+a/o/u 读 /k/；c+e/i 读 /θ 或 s/ | **c**asa「卡萨」、**c**ine「西内/θ内」 |
| **g** | g+a/o/u 读 /g/；g+e/i 读 /x/（同 j） | **g**ato（猫）、**g**ente（人们）「亨特」 |
| **gue/gui** | u 不发音，读「格/吉」 | **gue**rra（战争）「格拉」 |
| **que/qui** | u 不发音，读「克/基」 | **qué**（什么）「克」、**qui**ero「基埃罗」 |
| **d**（词尾/两元音间） | 轻化，接近轻咬舌的 th | Madri**d**、to**d**o |

## 三、r 与 rr：大舌音专项

| 写法 | 发音 | 例词 |
| --- | --- | --- |
| r（词中单写） | 单闪音：舌尖轻弹一下，≈日语/美音的 t 闪音 | pe**r**o（但是） |
| **rr** / 词首 r | 大舌颤音：舌尖连续颤动 | pe**rr**o（狗）、**r**ojo（红） |

**大舌音练法（每天 2 分钟，1–3 个月自然出来）**：
1. 放松舌尖，抵住上齿龈后方；
2. 用「tra-tra-tra → dra-dra-dra」快速连读找颤动感；
3. 或者含一小口水仰头「漱口」，体会舌头被气流带动的感觉。

> ⚠️ 练不出来完全不影响交流——大量母语者小时候也练了很久。先用单闪音顶着，别让 rr 卡住你的进度。
> 去 Forvo 对比听 pero / perro，这对最小对立组必须能听出区别。

## 四、重音规则：两条规则 + 一个补丁，全覆盖

西语单词的重音位置 100% 可预测：

1. **以元音、n、s 结尾** → 重音在**倒数第二个音节**：ca-**sa**、ha-**bla**-mos、**jo**-ven
2. **以其他辅音结尾** → 重音在**最后一个音节**：espa-**ñol**、ciu-**dad**、pro-fe-**sor**
3. **带重音符号 á é í ó ú** → 无条件重读标记处：ca-**fé**、te-**lé**-fo-no、**sá**-ba-do

> 重音符号还用来区分同形词：sí（是）vs si（如果）、tú（你）vs tu（你的）、qué（什么？）vs que（那个/连词）。

## 五、拼读实战：搭积木练习

按「辅音+元音」切音节，从左到右读就行：

```
ho-la          欧拉        你好
gra-cias       格拉-西亚斯  谢谢
bue-nos dí-as  布诶诺斯-地亚斯  早上好
cer-ve-za      塞尔-贝-萨   啤酒
a-e-ro-puer-to 阿诶罗普诶尔托  机场
```

自测：不查词典，试读 biblioteca（图书馆）、restaurante（餐厅）、universidad（大学）——
然后去 [SpanishDict](https://www.spanishdict.com/) 输入这三个词点发音验证。基本一致？恭喜，你已经「见词能读」了。
