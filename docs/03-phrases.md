# 🗣️ 西班牙语高频短语与数字

> 西语发音规则学完后，这一章的每个词你都应该**能自己读出来**——
> 拿不准就去 [SpanishDict](https://www.spanishdict.com/) 或 [Forvo](https://zh.forvo.com/languages/es/) 验证，把跟读当成拼读测验。

## 一、保命十句

| 西班牙语 | 意思 | 备注 |
| --- | --- | --- |
| ¡Hola! | 你好 | h 不发音：「欧拉」 |
| Buenos días / Buenas tardes / Buenas noches | 早上好 / 下午好 / 晚上好 | 按时段切换 |
| ¡Gracias! / Muchas gracias | 谢谢 / 非常感谢 | 回应：De nada 不客气 |
| Por favor | 请/劳驾 | 点单、请求万能后缀 |
| Perdón / Lo siento | 借过、抱歉 / 对不起 | Perdón 轻、Lo siento 重 |
| Sí / No / Vale | 是 / 否 / 好的 | Vale 是西班牙人的「OK」口头禅 |
| No entiendo | 我不明白 | 保命核心句 |
| ¿Puedes hablar más despacio? | 能说慢一点吗？ | despacio = 慢 |
| No hablo bien español | 我西语说得不好 | 缓冲万能句 |
| ¡Adiós! / ¡Hasta luego! | 再见 / 回头见 | Hasta luego 更口语 |

## 二、自我介绍模板（30 秒版）

```
¡Hola! Me llamo ___.               你好！我叫 ___。
Soy chino / china.                 我是中国人（男/女）。
Tengo ___ años.                    我 ___ 岁。
Vivo en Pekín / Shanghái.          我住在北京/上海。
Estoy aprendiendo español.         我正在学西班牙语。
¡Mucho gusto!                      很高兴认识你！
```

## 三、数字（比法语讲道理多了）

| 0–10 | cero uno dos tres cuatro cinco seis siete ocho nueve diez |
| --- | --- |
| 11–15 | once doce trece catorce quince |
| 16–19 | dieciséis diecisiete dieciocho diecinueve（=10+6…有规律） |
| 20/30/40/50 | veinte treinta cuarenta cincuenta |
| 60/70/80/90 | sesenta setenta ochenta noventa |
| 100 / 1000 | cien / mil |

- 组合规则：treinta y dos = 32（整十 y 个位），无任何法式数学；
- 价格常用句：¿Cuánto cuesta? 多少钱？ — Cuesta diez euros. 十欧。

## 四、点餐 / 酒吧（西语区的日常核心）

| 西班牙语 | 意思 |
| --- | --- |
| Una mesa para dos, por favor. | 两人一桌，谢谢。 |
| La carta, por favor. | 请给我菜单。 |
| Quiero una cerveza / un café con leche. | 我要一杯啤酒/拿铁。 |
| ¿Qué me recomiendas? | 你推荐什么？ |
| ¡Está muy rico! / ¡Qué rico! | 太好吃了！ |
| La cuenta, por favor. | 买单。 |
| Soy alérgico/a a ___. | 我对 ___ 过敏。 |

## 五、问路 / 购物 / 交通

| 西班牙语 | 意思 |
| --- | --- |
| ¿Dónde está el baño / el metro? | 洗手间/地铁在哪？ |
| ¿Está lejos / cerca? | 远吗/近吗？ |
| a la izquierda / a la derecha / todo recto | 左转 / 右转 / 直走 |
| ¿Cuánto cuesta? | 多少钱？ |
| Es muy caro. ¿Hay descuento? | 太贵了，有折扣吗？ |
| ¿Puedo pagar con tarjeta? | 能刷卡吗？ |
| Un billete para ___, por favor. | 一张去 ___ 的票。 |

## 六、星期与时间

- 星期：lunes 一 · martes 二 · miércoles 三 · jueves 四 · viernes 五 · sábado 六 · domingo 日
- hoy 今天 · mañana 明天（也是「早上」）· ayer 昨天
- ¿Qué hora es? 几点了？ — Son las tres. 三点。

## 七、日常反应词（听起来立刻地道）

| 西班牙语 | 场景 |
| --- | --- |
| ¡Claro! / ¡Por supuesto! | 当然！ |
| ¡Genial! / ¡Perfecto! | 太棒了/完美 |
| ¡No pasa nada! | 没关系（西班牙国民口头禅） |
| ¡Qué bien! / ¡Qué guay! | 真好！/真酷！（guay 是西班牙俚语） |
| A ver… | 我看看…/让我想想…（万能停顿词） |
| ¡Buen provecho! | 用餐愉快 |
| ¡Salud! | 干杯！（也用于别人打喷嚏时） |
