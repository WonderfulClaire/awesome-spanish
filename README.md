## 🗺️ 学习路径

```
第 1 周     ① 发音（超快，重点单独练大舌音 rr）
第 2–6 周   ② 语法变位 + ③ 高频短语（每天 1 表 + 5 句跟读）
第 2 个月起  ④ 沉浸：Dreaming Spanish 每天 30 分钟为主线
持续        西剧/西语歌/语伴，累计输入时长
```

## 🎧 随手听音三件套

1. **[SpanishDict](https://www.spanishdict.com/)** —— 查词+发音+变位一站式，西语第一工具；
2. **有道词典 App / 西语助手** —— 手机查词点喇叭；
3. **[Forvo 西语](https://zh.forvo.com/languages/es/)** —— 母语者真人录音（可选西班牙/拉美口音）。

## ⚠️ 西语专属提醒

1. **发音一周内解决**：这是三门里唯一能「速通」的发音系统，别拖；
2. **rr 练不出别停下**：用单闪音顶着继续学，1–3 个月自然出来；
3. **ser vs estar 早点建立直觉**：「是什么用 ser，怎么样/在哪用 estar」；
4. **主线交给 Dreaming Spanish**：CI 资源成熟度全语言第一，善用就是外挂。
